# 流量 Playbook（viral-tweet 参考文档）

## 一、算法机制速查（为什么这么写）

X 的推荐由神经网络预测各类互动概率后加权排序，可操作的杠杆按重要性排：

| 信号 | 权重/机制 | 写法对应 |
| --- | --- | --- |
| 回复 | 权重最高；"有回复的回复"约 75× 点赞。近期算法更偏深度讨论：50 条认真回复 > 500 个赞 | 结尾给可站队/可争论的观点；发布后 1 小时内认真回评论 |
| 停留时长 | 直接排序信号；<3 秒划走记负分 | 前 2 行留缺口，正文有信息密度，避免一眼扫完 |
| 负反馈（mute/block/不感兴趣） | 比正反馈强约一个量级，且拖累**整个账号**的后续分发 | 标题与正文一致；不引战不歪曲；宁少发不发水 |
| 外链 | 外链推文降权 | 链接放自回复 |
| 转发/引用 | 约 2× 点赞，但低于回复 | 金句要短到"转发时不用删" |
| 账号可信度 | 持续垂直输出建立话题权威；Premium 有小幅加权 | 固定主题域，签名档式身份标签 |
| 多媒体 | 图片/视频增加版面与停留 | 核心表格/数据可做成图 |

时效：热点话题的窗口通常 24-48 小时，旧内容蹭新热点（"xx 年前的话"式反差）同样吃到时效红利。

## 二、钩子库

通用要求：前 1-2 行独立成立；不说完结论；与正文一致。写 ≥3 个候选再选。

1. **数字反差**：`【A 看起来很小】，×【时间/次数】= 【大得离谱的 B】`
   > 每天只比同事多干 1%？5 年后你们差距是 37 倍。
   适用：有可算的数字链。最强通用型，具体数字天然可信。
2. **反共识宣言**：`所有人都觉得 X，但【信源】早就说了反的`
   > 都说要有钱先攒钱，孙宇晨 2016 年就说：攒钱是最慢的死路。
   适用：原文确有反常识观点。注意有事实托底，不歪曲。
3. **痛点叩问（排比）**：连续 2-3 个"你是不是……"递进 + 一句转折
   > 你是不是月薪 2 万还是存不下钱？你是不是也开始怀疑努力没用？2016 年有人把这事讲透了。
   适用：身份焦虑明确的题材。3 问以内，长了就疲。
4. **身份点名**：`每一个【身份】都该看看这个`
   > 建议每个刚工作的人把这段话听 10 遍。
   适用：金句本身够硬时，直接圈人。
5. **悬念缺口**：`【具体场景】的时候，我突然明白了一件事` / `听完这期我沉默了`
   > 凌晨改第 8 版方案的时候，我突然听懂了"可控负债"这个词。
   适用：故事型素材。
6. **争议自白**：`我不喜欢这个人，但这次他说得对`
   > 我一直叫他孙割，直到听完他 2016 年讲复利。
   适用：人物本身有争议时，矛盾态度反而真实。
7. **极端对比**：`同样 50 年，5% 和 30% 差 5 万倍`
   适用：素材里有一张对比表/一组阶梯数字。

选择顺序：优先与素材强绑定的一种，其次数字反差（通用性最强）；同主题多篇产出时轮换类型，避免账号钩子单一。

## 三、反模式清单（做了就掉流量）

- **标题党/货不对板**：点击有了，mute 也来了——负反馈是账号级惩罚，亏最大
- **Engagement bait**："转发抽奖""不转不是xx""求赞"——平台明令降权
- **钩子里说完结论**：读者不用点开，停留时长为 0
- **正文全是情绪没有信息**：高唤起开头 + 零密度正文 = 3 秒划走的负分
- **正文带外链**：降权；放自回复
- **一次说完所有观点的单条 500 字长推**：拆成 thread，每条一个论点
- **蹭歪曲性争议**：靠曲解原文引战，短期有回复、长期负反馈

## 四、复盘口径

发布 24-48 小时后看三个数（创作者后台）：

- **打开率**（曝光→点击/展开）：低 = 钩子问题，换钩子类型重发同素材
- **互动率**（互动/曝光）：低 = 内容密度或互动点问题
- **主页点击/关注转化**：低 = 缺身份标签，账号层面的问题，单篇救不了

同一素材 ≥2 个钩子版本分开发（间隔数天）是成本最低的测法；把赢的钩子类型记进选题库。
